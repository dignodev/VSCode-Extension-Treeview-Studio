# TreeView Studio Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.2] - 2026-03-04

### Added
- Smart cache system for faster tree generation
- Auto-invalidation when files change
- Manual cache clear command
- 6 language support (English, Spanish, French, German, Chinese, Japanese)
- Language switching via Command Palette
- Auto-detection of VS Code language
- Real-time options panel
- Search and filter functionality
- Expand/Collapse all features
- Customizable fonts (family and size)
- Collapsible entries option
- Copy to clipboard functionality
- Export to file option

### Changed
- Improved performance for large directories
- Enhanced UI/UX design

## [0.2.0] - 2025-XX-XX

### Added
- Context menu integration
- Configuration options (font family, font size, icons, hidden files, max depth)
- Multiple language support

### Changed
- Improved tree visualization

## [0.1.0] - 2025-XX-XX

### Added
- Initial release
- Basic directory tree generation
- Tree notation with ├──, └──, │
