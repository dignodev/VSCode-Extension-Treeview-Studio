# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | Currently supported |
| < 0.3   | Not supported |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by:

1. **Do NOT** create a public GitHub issue
2. Email the maintainer directly
3. Or use the private vulnerability reporting option on GitHub

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any possible fixes (if known)

## Security Considerations

- This extension reads directory structures from the local filesystem
- No data is sent to external servers
- All operations are performed locally
- The extension only accesses files within the workspace

## Response Time

We aim to acknowledge security reports within 48 hours and provide a timeline for fixes.
